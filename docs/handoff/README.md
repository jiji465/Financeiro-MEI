# Handoff entre pacotes de trabalho

Cada agente das fases 1–2 registra aqui (em `<WP>.md`, ex.: `P1-B.md`, `WP3.md`) os pedidos
que estão fora do seu escopo: mudanças em arquivos de outro pacote de trabalho, novas
dependências, ajustes de configuração raiz etc. O integrador da Fase 3 resolve todos os itens.
